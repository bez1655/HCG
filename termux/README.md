# HCG в Termux — всё с телефона

Три задачи, каждая — одна команда. Компьютер не нужен.

```
termux/1-СЕРВЕР.sh    развернуть игру на сервере
termux/2-GITHUB.sh    отправить код в репозиторий
termux/3-APK.sh       собрать приложение прямо на телефоне
```

---

## Сначала — важное про Termux

**Нужна версия из F-Droid, не из Google Play.**

👉 **https://f-droid.org/packages/com.termux/**

Версия в Google Play заброшена: в ней нет `openjdk-17` и части пакетов, без
которых сборка приложения невозможна. Если Termux уже стоит из Play — удалите
и поставьте из F-Droid.

---

## Подготовка (один раз)

Откройте Termux и выполните:

```bash
pkg update && pkg upgrade -y
pkg install -y wget unzip git openssh
termux-setup-storage
```

Последняя команда попросит разрешение на доступ к файлам — **разрешите**, иначе
готовое приложение некуда будет положить.

---

## Куда распаковать архив

Скачайте `HCG-3v1.zip` на телефон (обычно попадёт в «Загрузки»), затем:

```bash
cd ~
unzip ~/storage/downloads/HCG-3v1.zip
cd HCG-3in1
```

Если архив лежит в другом месте — найдите его:

```bash
ls ~/storage/downloads/
```

## ЧАСТЬ 1. Сервер

```bash
bash termux/1-СЕРВЕР.sh
```

Скрипт **не разворачивает игру на телефоне** — он подключается к вашему серверу
по SSH и запускает установку там. Телефон здесь вместо ноутбука.

Спросит адрес сервера и пользователя (обычно `root`), запомнит их и больше
спрашивать не будет. Пароль сервера попросит несколько раз — это нормально.

**Чтобы не вводить пароль каждый раз:**

```bash
ssh-keygen -t ed25519
ssh-copy-id root@VM-744336
```

Занимает 5–10 минут: основное время — пересборка образов на сервере.

После установки — два действия в Telegram:
1. Отправить боту **новую** команду `/start`
2. Проверить `/pending`

---

## ЧАСТЬ 2. GitHub

Сначала создайте репозиторий в браузере телефона:

👉 **https://github.com/new**

- имя: `HCG-Production`
- видимость: **Private**
- галочки README / .gitignore / license — **не ставить**

Затем получите токен доступа:

👉 **https://github.com/settings/tokens?type=beta**

- Repository access: только `HCG-Production`
- Permissions → **Contents: Read and write**
- Скопируйте токен сразу — показывается один раз

Теперь:

```bash
bash termux/2-GITHUB.sh
```

При входе: **логин** — ваш, **пароль** — токен (не пароль от аккаунта).

## ЧАСТЬ 3. Приложение для Android

```bash
bash termux/3-APK.sh
```

Скрипт сам поставит Java, Gradle, Android SDK и соберёт приложение. Готовый
файл появится в **Загрузках** под именем `HCG-Admin.apk` — откройте его через
файловый менеджер и установите.

### Что нужно знать заранее

| | |
|---|---|
| **Время** | 20–60 минут при первой сборке |
| **Место** | около 4 ГБ свободно |
| **Трафик** | ~1 ГБ (Gradle качает зависимости) |
| **Питание** | лучше подключить зарядку |

**Не сворачивайте Termux во время сборки** — Android может выгрузить процесс, и
всё придётся начинать заново. Включите блокировку пробуждения: потяните шторку
уведомлений и нажмите **Acquire wakelock** в уведомлении Termux.

### Почему это сложнее, чем на компьютере

Две особенности Termux, которые скрипт обходит автоматически:

**Инструмент `aapt2` в Termux поддерживает Android SDK не выше 34,** а Capacitor
по умолчанию просит 36. Скрипт понижает версию до 34 — на работу приложения это
не влияет.

**Gradle скачивает свой `aapt2`, собранный под процессоры компьютеров.** На
телефоне он не запускается. Скрипт подменяет его на местный, собранный под ARM.
Если первая попытка всё же упадёт — скрипт заменит файл в кеше Gradle и
повторит.

## Порядок, если делаете всё сразу

1. **Сервер** — первым. Без обновлённого сервера приложение не сможет войти.
2. **Приложение** — после сервера.
3. **Репозиторий** — когда удобно.

## Если что-то пошло не так

### Общее

| Сообщение | Решение |
|---|---|
| `command not found` | `pkg update && pkg upgrade -y` |
| `No space left on device` | Освободите место, нужно ~4 ГБ |
| Termux закрылся сам | Android выгрузил процесс — включите wakelock |

### Сервер

| Сообщение | Решение |
|---|---|
| `нет связи с сервером` | Проверьте адрес, сеть на телефоне, включён ли сервер |
| `Permission denied` | Неверный пароль или пользователь |
| Установщик упал | Подключитесь вручную: `ssh root@ваш-сервер` |

### GitHub

| Сообщение | Решение |
|---|---|
| `Authentication failed` | Введён пароль вместо токена |
| `Updates were rejected` | Репозиторий создан с README — удалите и создайте пустой |

### Приложение

| Сообщение | Решение |
|---|---|
| `openjdk-17 недоступен` | Termux из Google Play — переустановите из F-Droid |
| `aapt2 daemon failed` | Скрипт повторит сам; если нет — `rm -rf ~/.gradle/caches` и заново |
| `SDK location not found` | Удалите `apk/android` и запустите скрипт снова |
| Сборка падает без причины | Не хватает памяти. Закройте другие приложения |

Если собрать на телефоне не выходит — то же самое делается на компьютере через
`deploy/3-APK.ps1`. Результат идентичный.

## Честно о возможностях

**Сервер и GitHub с телефона** работают так же надёжно, как с компьютера:
Termux — полноценный терминал.

**Сборка приложения** сложнее. Android SDK официально не поддерживает сборку на
телефонах, и сообщество Termux обходит это своими сборками инструментов.
Скрипт применяет все известные обходы, но на слабом устройстве или при нехватке
памяти сборка может не пройти. Компьютер в этом случае надёжнее.
