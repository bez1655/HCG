# HCG — BUILD 2026-11-24.1 (исходники, кандидат на проверку)

База: архив HCG-2026-11-23.31. Изучены два отчёта внутри релиза: АУДИТ-08.6.md и АУДИТ-08.23.md. Отдельного отчёта аудита 23.31 в доступных материалах нет. Не является подтверждением полного закрытия всех замечаний или успешной выкладки.

## Изменения

- Доска: 65 уникальных узлов и маршрут от 0 до 64 берутся из серверных данных, а не из рисунка. Подложка со старыми противоречащими правилам значками закрыта; оригинальные логотип, ролики и изображения сохранены. Новая координатная сетка применяется один раз на старте при переходе со старой версии. Клетки игроков, их призы, ходы и герой не сбрасываются. Старая ручная калибровка заменяется, дальнейшая сохраняется.
- Якоря: контракты 6/20/36/50, фиксер 10/26/44/58, дроп 12/28/42/53, боссы 16/32/48/63. Клетка 64 — только Ядро и МЕГА-КРИСТАЛЛ. Убраны вымышленные стартовые уровень 7 и XP 70 из HUD.
- Дроп 12 доступен даже после обязательного отката на 9. Три кейса — купоны; номиналы 10/15% взяты из прежнего генератора. Выбор и код HAP создаются серверным Node crypto. Коды других кейсов не выдаются. Некорректный индекс не расходует событие. Убраны неканонические предметы и перемещения из кейсов. Сохранены ранее выданные купоны.
- FEVER удваивает только денежную скидку, не кристаллы и не МЕГА-КРИСТАЛЛ. Сервер использует рассчитанный приз, а не заново создаёт его из базовой клетки. Номинал скидки в тексте согласован с фактическим значением.
- В новых записях кабинета остаётся только наиболее ценный приз пачки; вытесненный приз не числится ожидающим выдачи. При списании не затрагивается случайный купон. Старые исторические записи автоматически не удаляются.
- Состояние HTTP, первоначальный socket-снимок и socket-патчи имеют одинаковую модель доступа: администратор видит полное состояние, игрок — своё состояние и ограниченный публичный профиль других. Внешние ключи чужих игроков псевдонимизированы; собственные призы и незавершённые события остаются доступны. Публичные журналы фильтруются от призов, купонов, админских сообщений и @хендлов. События призов отправляются адресно. HTTP-резерв клиента теперь передаёт сессионную авторизацию.
- Незавершённые RPG-события и кейсы восстанавливаются при переподключении; новый бросок до завершения запрещён. Недопустимые варианты RPG не расходуют проверку. Добавлена подпись о расходовании хром-печати при любом результате D20. Убрана неиспользуемая функция ранга от кредитов.
- Результат финиша больше не описывает возврат на старт как штраф; текст о призах не утверждает, что более слабый приз заменил сильный.
- Метки сервера и бота согласованы: 2026-11-24.1. Добавлены регрессионные тесты, тесты игрового состояния переведены на административный API там, где требуются настоящие ID.

## Проверки и ограничения

Фактически выполнено локально: синтаксический разбор 130 TS/TSX-файлов и 32 независимые runtime-проверки чистых модулей (геометрия и якоря, дроп, FEVER, иерархия, круг, +1 ход, шкала скидки, генерация купонов, проекция приватности). Все прошли.

Не выполнено: полная проверка типов, npm run build, Vitest/E2E, Docker, проверка интерфейса в Telegram WebView, производительность Android и живой сервер. npm ci --offline завершился ошибкой отсутствующего кэша, обычная установка не завершилась в отведённом окружении. Старый dist исключён, поскольку он не содержит эти правки. Архив не содержит node_modules и рабочую папку data (включая сохранения/учётные данные). Не удаляйте и не заменяйте существующий том data при развёртывании. Выполните резервное копирование существующего состояния и калибровки до обновления.

Проверка перед выкладкой в среде Node 22+ с установленными зависимостями:

```sh
npm ci
npm run lint:types
npm run test:all
```

Dockerfile собирает dist заново. Запускать только после успешной сборки и проверки на тестовом окружении. Не считать исправления установленными на VPS.

Оставшиеся задачи из прежних аудитов: рефакторинг серверных обработчиков админки, полноценная диагностика socket-админки, проверка всех кнопок в Telegram, замеры FPS и подтверждение живой выкладки. Оригинальное видео правил не изменено по канону. Отдельный последний аудит требуется для сверки полного списка его замечаний.
