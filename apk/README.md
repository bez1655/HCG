# Hapstore — приложение для Android

Отдельное приложение с иконкой на рабочем столе. Вход **только по логину и
паролю**, Telegram не нужен.

---

## Что это и чем отличается от версии в Telegram

| | В Telegram | Это приложение |
|---|---|---|
| Как открывается | кнопка в боте | иконка на телефоне |
| Вход | сам узнаёт по аккаунту | логин и пароль |
| Кому | игрокам | **вам, администратору** |
| Игра и правила | одинаковые | одинаковые |

**Важно:** это не отдельная игра. Приложение подключается к тому же серверу,
показывает ту же доску и тех же игроков. Ход, сделанный здесь, виден в
Telegram, и наоборот.

Отсюда следствие: **без интернета приложение не работает** — вся игра живёт на
сервере, иначе состояние двух копий разъехалось бы.

---

## Почему интерфейс не скопирован

Приложение собирается из **тех же исходников**, что и основная версия.
Различие ровно одно — адрес сервера, который вшивается при сборке.

Копия интерфейса на 5500 строк начала бы расходиться с оригиналом в первую же
неделю, и две версии стали бы по-разному понимать, например, вход. Поэтому
копии нет.

---

## Что нужно один раз установить

1. **Node.js 20 или новее** — https://nodejs.org (кнопка LTS)
2. **Android Studio** — https://developer.android.com/studio
   При первом запуске он сам предложит скачать SDK — согласитесь.
3. **JDK 17** — обычно ставится вместе с Android Studio.
   Проверка: `java -version` должно показать 17 или выше.

## Сборка: шаг за шагом

### Шаг 1. Указать адрес сервера

В папке `apk` создайте файл `.env`:

```
VITE_API_BASE_URL=https://hcg.bez12.store
```

Замените на свой домен, если он другой.

> Обязательно `https://`. Android блокирует незашифрованные соединения, а по
> ним ходят пароли. Сборка с `http://` будет остановлена намеренно.

### Шаг 2. Установить зависимости

В командной строке, находясь в папке `apk`:

```bash
npm install
```

### Шаг 3. Собрать веб-часть

```bash
npm run build:web
```

Скрипт соберёт интерфейс и **проверит**, что адрес сервера действительно попал
в сборку. Если нет — остановится с ошибкой, а не выдаст нерабочее приложение.

Ожидаемый результат:

```
✅ Готово: apk/www
   Адрес сервера вшит в сборку: https://hcg.bez12.store
```

### Шаг 4. Создать Android-проект

Только при первой сборке:

```bash
npx cap add android
```

Появится папка `android` — это и есть проект для Android Studio.

### Шаг 5. Перенести файлы в проект

```bash
npx cap sync android
```

**Эту команду нужно повторять после каждого изменения игры.**

### Шаг 6. Собрать APK

**Вариант А — через командную строку (быстрее):**

```bash
cd android
./gradlew assembleDebug
```

В Windows PowerShell:

```powershell
cd android
.\gradlew.bat assembleDebug
```

Готовый файл появится здесь:

```
apk/android/app/build/outputs/apk/debug/app-debug.apk
```

**Вариант Б — через Android Studio (нагляднее):**

```bash
npx cap open android
```

Дождитесь окончания индексации (индикатор внизу окна), затем меню
**Build → Build Bundle(s) / APK(s) → Build APK(s)**.
По завершении нажмите **locate** во всплывающем уведомлении.

### Шаг 7. Установить на телефон

1. Скопируйте `app-debug.apk` на телефон (кабелем, через облако или мессенджер)
2. Откройте файл на телефоне
3. Android предупредит об установке из неизвестного источника — разрешите
4. Готово, иконка появится на рабочем столе

## Вход в приложение

Логин и пароль — те же, что в веб-версии:

- **Логин:** значение `ADMIN_LOGIN` из `.env` на сервере (по умолчанию `admin`)
- **Пароль:** тот, для которого сделан `ADMIN_PASSWORD_HASH`

Забыли пароль — задайте новый на сервере:

```bash
cd /var/www/hcg
npm run hash-password -- 'новый-пароль'
```

Полученную строку впишите в `.env` как `ADMIN_PASSWORD_HASH` и перезапустите:

```bash
docker compose up -d --force-recreate hcg_app
```

## Иконка приложения

Иконка лежит здесь:

```
apk/resources/icon.png
```

Чтобы поставить свою — **просто замените этот файл**. Больше ничего делать не
нужно: при сборке из него автоматически создаются 74 файла всех нужных
размеров, включая круглые и адаптивные иконки для Android 8 и новее.

### Требования к файлу

| | |
|---|---|
| Формат | PNG |
| Размер | **1024 × 1024** пикселей, строго квадрат |
| Фон | непрозрачный (прозрачность станет чёрной) |
| Отступы | оставьте свободное поле по краям — Android обрезает иконку в круг или скруглённый квадрат, и рисунок вплотную к краю потеряет углы |

### Проверить свой файл перед сборкой

```bash
cd apk
python3 -c "
import struct
d = open('resources/icon.png','rb').read()
print('PNG:', d[:8] == b'\x89PNG\r\n\x1a\n')
w, h = struct.unpack('>II', d[16:24])
print(f'размер: {w}x{h}', '— годится' if w == h >= 1024 else '— НЕ ГОДИТСЯ')
"
```

### Пересобрать только иконки

Если приложение уже собрано и нужно поменять лишь иконку:

```bash
cd apk
npm run icons
cd android && ./gradlew assembleDebug --no-daemon
```

### Заставка при запуске

Рядом можно положить `resources/splash.png` — картинку, которая показывается
первую секунду после запуска. Требования: **2732 × 2732**, важное содержимое
по центру (края обрезаются на разных экранах). Файл необязателен.

## Обновление приложения после изменений в игре

```bash
cd apk
npm run build:web
npx cap sync android
cd android && ./gradlew assembleDebug
```

Новый APK ставится поверх старого — данные сохраняются.

## Если что-то пошло не так

| Симптом | Причина | Решение |
|---|---|---|
| «Не задан адрес игрового сервера» | Нет файла `.env` | Создайте его (шаг 1) |
| Приложение открылось, но пустой экран | Не выполнен `npx cap sync android` | Выполните шаг 5 |
| «Ошибка связи с сервером» при входе | Сервер недоступен или адрес неверный | Откройте адрес в браузере телефона — должна открыться игра |
| «Неверный логин или пароль» | Пароль от сервера, а не от Telegram | Используйте `ADMIN_LOGIN` и его пароль |
| Gradle: `SDK location not found` | Android Studio не настроен | Запустите Android Studio, дайте ему скачать SDK |
| Gradle: `Unsupported Java version` | Старая Java | Нужен JDK 17+ |
| Вход проходит, но доска не грузится | Сервер не пускает приложение | Проверьте, что на сервере стоит версия от 30.07 или новее |

## Про безопасность

- Приложение **не хранит пароль** — только временный токен сессии, как и
  браузер. Токен живёт 7 дней, потом нужен повторный вход.
- Сервер пускает приложение по отдельному правилу CORS: разрешены только
  адреса Android-обёртки, ваш домен и Telegram. Посторонний сайт получить
  доступ не может — это проверено тестом.
- Debug-APK **не подписан** для магазина. Для личного использования этого
  достаточно; для публикации в Google Play нужна подпись ключом
  (`assembleRelease` и keystore).

## Установка на несколько устройств

Один и тот же APK ставится на любое число телефонов — пересобирать не нужно.
Но помните: вход администратора один на всех, и любой, у кого есть APK и
пароль, получит полный доступ к панели.
