Этот архив нужен ДВА раза: один раз на старом сервере, один — на новом.

Подробности — в файле ПЕРЕЕЗД-НА-НОВЫЙ-СЕРВЕР.md (тут же, рядом).
Ниже — только последовательность действий.


────────────────────────────────────────────────────────────────────
  ШАГ 1. На СТАРОМ сервере (PuTTY)
────────────────────────────────────────────────────────────────────

Залейте этот архив на старый сервер и распакуйте:

    cd /root
    apt-get install -y unzip
    unzip -o HCG-ПЕРЕЕЗД.zip -d /root/hcg-переезд
    cd /root/hcg-переезд
    bash deploy/СНЯТЬ-СО-СТАРОГО.sh

Скрипт соберёт всё незаменимое в один файл:
    /root/HCG-ПЕРЕЕЗД-дата.tgz

СМОТРИТЕ НА ГАЛОЧКИ. Если увидите красные ✗ — не переезжайте,
сначала разберитесь. Пустой SESSION_SECRET или ADMIN_PASSWORD_HASH
означает, что новый сервер просто не запустится.


────────────────────────────────────────────────────────────────────
  ШАГ 2. Забрать себе (PowerShell на Windows)
────────────────────────────────────────────────────────────────────

    scp root@СТАРЫЙ-IP:/root/HCG-ПЕРЕЕЗД-*.tgz C:\Users\%USERNAME%\Desktop\

Не пропускайте этот шаг. Копия у вас на руках — единственная страховка,
если старый сервер отключат внезапно.

ВНИМАНИЕ: внутри пароли и токен бота. Не пересылайте в мессенджерах.


────────────────────────────────────────────────────────────────────
  ШАГ 3. Залить на НОВЫЙ сервер (PowerShell)
────────────────────────────────────────────────────────────────────

    scp C:\Users\%USERNAME%\Desktop\HCG-ПЕРЕЕЗД-*.tgz root@НОВЫЙ-IP:/root/
    scp C:\Users\%USERNAME%\Desktop\HCG-ПЕРЕЕЗД.zip   root@НОВЫЙ-IP:/root/


────────────────────────────────────────────────────────────────────
  ШАГ 4. Развернуть (PuTTY, НОВЫЙ сервер)
────────────────────────────────────────────────────────────────────

    cd /root
    apt-get update && apt-get install -y unzip
    unzip -o HCG-ПЕРЕЕЗД.zip -d /root/hcg-новый
    cd /root/hcg-новый
    bash deploy/ПОСТАВИТЬ-НА-НОВЫЙ.sh /root/HCG-ПЕРЕЕЗД-*.tgz

Займёт 5–15 минут. Скрипт сам поставит Docker и Caddy, восстановит
пароли, зальёт игроков, поднимет сертификаты и всё проверит.

ВАЖНО: распаковывайте в /root/hcg-новый, НЕ в /var/www/hcg.
Копировать папку саму в себя нельзя — скрипт на этом остановится.


────────────────────────────────────────────────────────────────────
  ШАГ 5. Переключить DNS
────────────────────────────────────────────────────────────────────

В панели регистратора домена hcg.bez12.store:
    A-запись  →  IP нового сервера

Обновление занимает от 5 минут до 2 часов.
Caddy выпустит сертификат сам, как только DNS обновится.


────────────────────────────────────────────────────────────────────
  ШАГ 6. Отключить прокси — в Голландии он не нужен
────────────────────────────────────────────────────────────────────

Делайте ТОЛЬКО после того, как убедились, что игра работает.

    cd /var/www/hcg
    bash deploy/БЕЗ-ПРОКСИ.sh

Скрипт сначала проверит настоящим запросом, доступен ли Telegram
напрямую. Если да — отключит прокси и станет заметно стабильнее.
Если нет — не тронет ничего.


────────────────────────────────────────────────────────────────────
  ШАГ 7. Старый сервер НЕ УДАЛЯТЬ ещё сутки
────────────────────────────────────────────────────────────────────

Оплатите ещё один период. Пока новый не отработал день без жалоб,
старый — ваш путь назад. Это дешевле любой ошибки.


════════════════════════════════════════════════════════════════════
  ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
════════════════════════════════════════════════════════════════════

Игра открылась, но доска ПУСТАЯ — данные не доехали:
    docker run --rm -v hapstore-data:/data:ro alpine ls -la /data
    Если пусто — повторите шаг 5 скрипта установки.

Сайт не открывается, «нет защищённого соединения»:
    systemctl status caddy
    journalctl -u caddy -n 30
    Чаще всего DNS ещё не обновился — подождите.

Бот молчит:
    docker logs hcg_bot --tail 50
    Если отключали прокси — откат:
    cp .env.до-отключения-прокси-* .env && docker compose up -d

Ничего не помогает — старый сервер ещё жив, верните DNS на него.
