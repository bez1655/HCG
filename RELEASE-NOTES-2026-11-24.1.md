# HCG Production Release — Build 2026-11-24.1

Финальный проверенный релизный пакет для развёртывания на сервере.

## Ключевые изменения и исправления

1. **Android Client удалён:**
   - Каталог `android_client/` полностью исключён из состава серверного веб-релиза, включая локальные keystore-файлы.
   - В `.gitignore` добавлены правила блокировки `*.keystore`, `*.jks`, `keystore/`.

2. **Единый путь серверной сборки (Fix Deployment Mismatch):**
   - В `package.json`, `Dockerfile` и `deploy/test-server.sh` пути компиляции сервера приведены к единому стандарту `dist/server.cjs`.
   - Тестовый сервер `deploy/test-server.sh` запускается штатно без сбоев `Cannot find module`.

3. **Уникальная псевдонимизация игроков (Token Collision Fix):**
   - Чужие игроки передаются на клиент с детерминированным безопасным хеш-ключом `public_<sha256>`.
   - Полностью устранены дублирующиеся React-ключи `key={player.id}` и коллизии кругового смещения фишек на общих клетках в `BoardView.tsx`.

4. **Кнопка подтверждения бонуса в Telegram-боте (`approve_turn_bonus`):**
   - Исправлена ручная выдача хода администратором при наличии блокирующего приза.
   - Кнопка подтверждения бонуса больше не падает с `410 Запрос уже обработан`, если администратор инициировал выдачу через команду `/grant_turn`.

5. **Финиш и завершение круга (Ядро Сети, Клетка 64):**
   - Устранено мгновенное обнуление клетки при проходе финиша. Фишка остаётся на клетке 64 (Ядро Сети) до начала следующего круга.
   - Снятие с клетки 64 на клетку 0 сопровождается штатным системным логом `lap_unwrap`.

6. **Скрипт синхронизации `deploy/2-GITHUB.sh`:**
   - Добавлен перехват реального статуса `git push` и проверка `Everything up-to-date`.
   - Исключены ложные сообщения об успехе при отсутствии коммитов.
   - Добавлено предупреждение о ветке по умолчанию (`main` vs `master`).
   - Расширен фильтр проверки секретов перед отправкой.

7. **Очистка релизного пакета:**
   - Удалены устаревшие артефакты `bot/dist/`.
   - Проверены права на исполняемые bash-скрипты.
   - Пройден полный синтаксический и runtime-тест `audit-smoke.cjs` (130 файлов, 32 проверки).
