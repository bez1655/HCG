------------------------------------------------
Вкладка «Бейджик»
------------------------------------------------
Нажмите «Загрузить файл» и выберите:
  tilda-badge-800.png

Это квадратная картинка 800×800. Её Тильда подставляет в соцсети,
если отдельную картинку для соцсетей не зададите.


------------------------------------------------
Вкладка «Соцсети»
------------------------------------------------
Ничего руками не печатайте: заголовок и описание возьмутся из «Главное»,
картинка — из «Бейджик».

Проверьте превью: не должно быть «Blank page».
Если видите Blank page — вернитесь в «Главное», сохраните заголовок ещё раз.


------------------------------------------------
Вкладка «SEO»
------------------------------------------------
Нажмите «Настроить отображение в поисковой выдаче» и вставьте:

Title (заголовок в Google):
HCG — Hapstore Cyber Game | киберпанк-квест

Description (сниппет, до ~160 знаков):
Настольная киберпанк-игра Hapstore. Бросайте кубик, открывайте клетки, копите призы. Играйте в Telegram: @hcg1_bot

Картинка для выдачи (если спросит):
  tilda-og-1200x630.png     размер 1200×630 — стандарт для Telegram, VK, Facebook


------------------------------------------------
Вкладка «Дополнительно»
------------------------------------------------
МИКРОАНИМАЦИЯ
не включайте «Отключить эффект…» — оставьте как есть (кружок пустой)

АДАПТИВНОСТЬ
не включайте «Отключить адаптивность» — сайт должен открываться на телефоне

НОМЕР ОЧЕРЕДНОСТИ
10 — можно не трогать (это порядок страниц внутри Тильды, на игру не влияет)
если это главная страница сайта — поставьте 1

ЛЕЙБЛ

------------------------------------------------
Пошагово на телефоне
------------------------------------------------
1. Вкладка Главное → заголовок и описание → Сохранить
2. Вкладка Бейджик → Загрузить файл → tilda-badge-800.png → Сохранить
3. Вкладка SEO → настроить выдачу → title и description выше → картинка 1200×630
4. Вкладка Соцсети → убедиться, что превью не Blank page
5. Дополнительно → лейбл HCG, адаптивность не отключать → Сохранить
6. Опубликуйте сайт (кнопка «Опубликовать» у Тильды), иначе в интернете останется старое.
