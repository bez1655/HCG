## Сначала останови игру Али

Заказчик просил **остановить игру**, пока переносишь исправления. Не удаляй данные.

На VPS (PuTTY), готовые команды:

```bash
cd /var/www/ali
docker compose ps
docker compose stop
docker ps | grep ali
```

Контейнеры `ali_*` должны быть **Stopped**, не удалены. Том данных Али не трогать.  
HCG (`hcg_*`) не останавливать.

Если compose лежит в другом каталоге — найди:

```bash
docker ps -a --format '{{.Names}}' | grep -i ali
```

и останови только эти контейнеры: `docker stop <имя>`.

После остановки напиши заказчику одной фразой: «Игра Али остановлена, данные на месте». Дальше правь код и выкладывай, когда скажет включать.

## Состояние HCG (эталон логики, не копипаст доски)

Ветка `server-2026-08-19`. Маркер **`2026-08-25.1`**.

Уже в HCG (перенеси аналоги в Али):

1. **Падение APK / белый экран в админке** — `ReferenceError: initPlayerEdit is not defined`.  
   В таблице игроков при рендере вызывали функцию, которую удалили.  
   В HCG это строка в `src/components/AdminConsole.tsx` внутри `.map` игроков.  
   **Сделай в Али:** найди `initPlayerEdit(` и **удали вызов**. Синхронизация полей — только в `useEffect` по `gameState.players`, и только если строка не `dirty`. Не вызывай `setState` из render.

2. **Бот работает, приложение падает** — белый экран, потому что:
   - `html/body/#root` без тёмного фона (по умолчанию белый);
   - CrashGuard не оборачивал всё приложение;
   - при медленном сокете клиент **стирал сессию** и кидал на логин;
   - патч `state:patch` до первого снимка оставлял `gameState = null`.  
   В HCG: тёмный фон в `index.css`; `CrashGuard` в `main.tsx`; в `App.tsx` не делать `localStorage.clear()` из‑за таймаута, fallback `GET /api/state`, при патче без снимка слать `client:resync`; экран `admin` без роли `admin` показывать доску.

3. Админ бота при «ИГРАТЬ» получает сессию `role: admin` (`.env` + `admin_list.json`, без хардкода @ника). Игрокам писать «Администратор».

4. Живое обновление доски без ухода с экрана (`client:resync`, не крутить `initPlayerEdit` на каждый кадр).

5. История `/history`: клетка за клеткой, дата в каждой строке, причина простым языком. В HCG — `src/game/playerHistory.ts` → `expandHistoryLines`. **В Али этого ещё нет — сделай.** Клетки бери из доски Али.
