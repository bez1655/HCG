КОРОТКОЕ ОПИСАНИЕ  (/setabouttext)  — до 120 символов
----------------------------------------
Hapstore Cyber Game: киберпанк-квест по доске. Бросайте кубик, собирайте призы, дойдите до финиша.


ПОЛНОЕ ОПИСАНИЕ  (/setdescription)  — до 512 символов
----------------------------------------
HCG — настольный киберпанк-квест магазина Hapstore внутри Telegram.

Откройте мини-приложение, получите псевдоним и ходите по доске. Кубик бросается после одобрения хода. Призы копите в кабинете «Мои призы».

Игроки видят только игровые имена. Администратор видит и псевдоним, и @хендл.

Игра: https://hapstore.cyber-game.online
Команды: /start · /play · /help


КОМАНДЫ ДЛЯ ВСЕХ  (/setcommands)
Вставляйте строго так: команда, пробел, описание. Без слэша в начале.
----------------------------------------
start — Открыть игру HCG
play — Играть сейчас
help — Как играть и что умеет бот
prizes — Мои призы


КОМАНДЫ ТОЛЬКО АДМИНУ
Их НЕ добавляйте в /setcommands — игроки увидят меню. Это шпаргалка для вас.
----------------------------------------
/requests — сводка: заявки, запросы ходов, невыданные призы
/pending — заявки на регистрацию с кнопками
/players — полный список игроков файлом

/turns кого [сколько] — выдать ходы без заявки
  пример: /turns Бэтмен 3

/msg кого текст — личное сообщение
  /msg Бэтмен Ваш приз готов
  /msg @ivan Ваш приз готов
  псевдоним из двух слов — в кавычках

/all текст — написать всем игрокам
/proxies — рабочие прокси с парсера

/admin_logs [поиск] — журнал игры
/set_admin @username — добавить администратора
/list_admins — список администраторов
/reload_admins — перечитать список

/history ник — история ходов игрока
/report — отчёт за день
/prizes — призы (у игрока — свои)

Кого угодно можно назвать псевдонимом или @хендлом. Игроки видят только псевдонимы.
Из чата игры: напишите псевдоним в сообщении — человек получит текст в Telegram.
