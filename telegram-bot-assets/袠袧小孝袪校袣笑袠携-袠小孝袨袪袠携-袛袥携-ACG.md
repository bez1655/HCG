# Инструкция агенту ACG: понятная история ходов

Сделай в Али **то же**, что уже сделано в HCG. Репозиторий Али отдельный. Не трогай HCG, токены и доски не смешивай.

## Задача

Команда истории игрока (в HCG это `/history <кто>`) сейчас выдаёт кашу: непонятно, **с какой клетки на какую** ушла фишка, **почему**, и **когда**.

Актуально на HCG **2026-09-06.1** (формат 29.3+): **одна строка на бросок**, не клетка-за-клеткой.

Нужно:

1. Одна строка на бросок: дата, кубик, откуда, куда приземлился, если клетка сдвинула — «штраф/бонус на КОНЕЧНУЮ».
2. Дата из `at` (мс), `toLocaleString("ru-RU")`. Штамп только-часы (`7:11:33 PM`) **не** делать «сегодня» — «дата неизвестна».
3. Причина простым языком. Сырой лог («выбросил и переместился») человеку не показывать.
4. Имена клеток — с **доски Али**.
5. Недатированный префикс оставлять, только если `toCell <= fromCell` первого датированного броска; прочее без даты выкинуть.
6. Позиции из админки не переписывать массово из истории.

Пример:

```
1. [28.08.2026, 14:30] выпало 6 — с 6 на 12 — штраф на 9
2. [25.08.2026, 10:24] выпало 2 — с 4 на 6
```

## Где править в Али

Найди модуль истории (в HCG: `src/game/playerHistory.ts`, выдача `/history`, API вроде `/api/admin/player-history`).

Там же:

- запись ходов в файл (`player-moves.jsonl` или аналог) — в каждой записи уже должны быть `at` (мс), `fromCell`, `toCell`, `steps`, `note`;
- разбор старых строк журнала, если файла ещё нет;
- форматтеры текста/HTML для Telegram.

Передай в форматтер **список клеток доски Али**, чтобы вместо голого номера писать имя особой клетки.

Дата: `toLocaleString("ru-RU", { day, month, year, hour, minute })` из поля `at`. Если `at` нет — пиши «дата неизвестна», не оставляй пусто.

Если в старой записи нет `fromCell` — возьми `toCell` предыдущего хода этого игрока.

## Проверка

`/history` по игроку, у которого были броски: видны все шаги, даты, причины. Приз не теряется. Файл-выписка (если есть) совпадает по смыслу с сообщением.

Не ломай данные игроков. Версию сборки Али подними свою.
