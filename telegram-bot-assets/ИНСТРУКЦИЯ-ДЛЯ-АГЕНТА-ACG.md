# Инструкция агенту ACG (Али-Баба)

Сделай **то же самое**, что уже сделано в HCG: администратор, который открыл игру **через Telegram** (кнопка «ИГРАТЬ» / Mini App), должен сразу иметь доступ к **внутриигровой админке**.

Это **другой проект**. Не трогай HCG. Не копируй доску, клетки, токен, домен и package id HCG.

---

## Что нельзя смешивать

| | HCG | ACG (Али) |
|---|---|---|
| Каталог на VPS | `/var/www/hcg` | `/var/www/ali` (или актуальный путь Али) |
| Контейнеры | `hcg_app` `hcg_bot` `hcg_proxy` | `ali_*` |
| Домен | `hcg.bez12.store` | `ali.bez12.store` |
| Бот | свой токен, не HCG | свой токен в `.env` Али |
| Package id APK | `store.bez12.hcg` | `store.bez12.ali` |
| Порт | 3001→3000 | свой (часто 3002) |

`WEB_APP_URL` и `TELEGRAM_BOT_TOKEN` Али **не** должны указывать на HCG. Если бот Али открывает HCG — это баг, чини `.env` Али.

---

## Зачем

Сейчас типичная схема (как было в HCG):

- Бот знает админов: `TELEGRAM_ADMIN_USERNAME` + файл `admin_list.json` + команды `/set_admin`.
- Мини-приложение при входе через Telegram **всегда** выдаёт роль `player`.
- Кнопка «АДМИНКА» завязана на `userRole === "admin"`.
- Итог: админ жмёт «ИГРАТЬ» и админки нет. Веб-логин паролем работает отдельно.

Нужно: тот же человек, кого бот считает админом, при открытии Mini App получает **сессию с ролью admin**.

---

## Как должно работать после правки

1. В `.env` Али задан `TELEGRAM_ADMIN_USERNAME=@ник` **без хардкода ника в исходниках**.
2. Доп. админы — `/set_admin @ник` (файл `admin_list.json` в томе данных).
3. Админ пишет боту `/start` → «ИГРАТЬ».
4. Сервер проверяет `initData` Telegram.
5. Если хендл есть в списке админов бота:
   - **есть запись игрока** → токен с `id` этого игрока и `role: "admin"` (фишка на доске + админка);
   - **нет записи игрока** → токен служебного `admin_user` (или аналог) и `role: "admin"` (только админка, без регистрации).
6. Клиент сохраняет `role` и показывает пункт меню админки.
7. Обычный игрок по-прежнему `player`, админки нет.
8. Старый вход логином/паролем из `.env` не ломать.

## Где править (ищи аналоги в репозитории Али)

HCG-имена — ориентир, у Али файлы могут называться иначе.

1. **Точка входа Mini App**  
   `POST /api/telegram/auth` (проверка `initData`).  
   Сейчас после нахождения игрока roughly:  
   `role: player.role === "admin" ? "admin" : "player"`.  
   У зарегистрированных игроков `role` почти всегда `"player"` — поэтому админки нет.

2. **Список админов бота**  
   Тот же источник, что у команд `/set_admin` / `/list_admins`:
   - `TELEGRAM_ADMIN_USERNAME` из `.env`;
   - `{DATA_DIR}/admin_list.json`.  
   Вынеси чтение в маленькую функцию (как `isTelegramAdminHandle(username, dataDir, envAdmin)`).  
   **Не** вшивай конкретный @хендл в код.

3. **Клиент**  
   После успешного `/api/telegram/auth` выставить `userRole` из ответа сервера (`data.role`).  
   Кнопка админки только при `userRole === "admin"`.  
   Сокет должен слать токен с ролью `admin`, иначе сервер не пустит в admin-события.

4. **Приватность админов** (сделай заодно, как в HCG):
   - игрокам в журнале и чате не светить @хендл админа (писать «Администратор»);
   - `/list_admins` только админам;
   - в политике/сайтах не публиковать личный @ админа — контакт через бота Али.

## Алгоритм в `/api/telegram/auth` (псевдокод)

```
проверить initData подписью токена бота Али
handle = @username из initData
player = найти по telegramId, иначе по handle
isAdmin = handle в (TELEGRAM_ADMIN_USERNAME ∪ admin_list.json)

если нет player:
  если isAdmin → выдать сессию admin_user / role=admin  (200)
  иначе → 404 needsRegistration

если есть player:
  sessionRole = isAdmin или player.role==="admin" ? "admin" : "player"
  выдать token(player.id, sessionRole) и role=sessionRole
```

Не логируй хендл админа в клиентские логи.

## Проверка

1. `.env` Али: свой бот, свой `WEB_APP_URL=https://ali.bez12.store` (или актуальный домен Али).
2. `TELEGRAM_ADMIN_USERNAME` = твой рабочий @ник.
3. Этим аккаунтом `/start` у **бота Али** → ИГРАТЬ.
4. Есть пункт админки. Игроки, доски, ходы Али на месте.
5. Вторым аккаунтом (не админ) — админки нет.
6. `/set_admin @помощник` → помощник после `/start` и ИГРАТЬ тоже видит админку (после пересборки, тот же том `admin_list.json`).
7. `docker ps` — крутятся **ali_***, не подменён hcg-токен.

## Сборка / версия

Подними маркер сборки Али (свой, не копируй номер HCG). После выкладки админ должен заново нажать `/start` и «ИГРАТЬ», чтобы получить новый токен с ролью admin. Старая сессия в localStorage может остаться `player` — новый вход через Telegram перекрывает её.

Коммиты Али — в репозиторий Али. Данные игроков Али не трогать (том Docker).
