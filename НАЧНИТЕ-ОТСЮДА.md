# HCG — три в одном

В архиве всё сразу:

| | Что это | Где |
|---|---|---|
| **1** | Игра, сервер и Telegram-бот | корень архива |
| **2** | Набор для сборки приложения Android | папка `apk/` |
| **3** | Скрипты установки — по одной команде | папка `deploy/` |

---

## С чего начать

Откройте **`ИНСТРУКЦИЯ.md`** — там пошагово, с точными путями и ссылками.

Если коротко — три команды, каждая в своей среде:

**Всё на сервере (рекомендую — компьютер нужен только для загрузки архива):**

```
deploy/1-СЕРВЕР.sh      развернуть игру
deploy/2-GITHUB.sh      отправить в репозиторий
deploy/3-APK.sh         собрать приложение для Android
```

**Или с компьютера (Windows):**

```
deploy/2-GITHUB.ps1     PowerShell — отправить в репозиторий
deploy/3-APK.ps1        PowerShell — собрать приложение
```

**Только с телефона (Termux) — компьютер не нужен:**

```
termux/1-СЕРВЕР.sh      подключиться к серверу и развернуть
termux/2-GITHUB.sh      отправить в репозиторий
termux/3-APK.sh         собрать приложение прямо на телефоне
```

Инструкция для телефона — в `termux/README.md`.
Важно: нужен Termux из F-Droid, не из Google Play.

---

## Порядок, если делаете всё сразу

1. **Сервер** — первым. Без обновлённого сервера приложение не сможет войти.
2. **Приложение** — после сервера.
3. **Репозиторий** — когда удобно.

## Что нужно установить

**Для сервера** — ничего, всё уже стоит.

**Для репозитория** — Git: https://git-scm.com/download/win

**Для приложения Android:**
- Node.js 20 LTS — https://nodejs.org
- Android Studio — https://developer.android.com/studio
  *(при первом запуске согласитесь скачать SDK — это обязательно)*

Скрипты сами проверят, чего не хватает, и подскажут ссылку.

---

## Важное про приложение

Это **не отдельная игра**. Оно подключается к тому же серверу: ход из
приложения виден в Telegram и наоборот. Без интернета не работает — вся игра
живёт на сервере.

Вход — по логину и паролю, Telegram не нужен. Это версия для вас как
администратора.

## Осталось сделать вручную

Скрипты этого не умеют:

1. 🔴 **Отозвать токен бота**, присланный в переписку. Он скомпрометирован
   независимо от всего остального.
   Новый: @BotFather → `/mybots` → Bot Settings → API Token

2. 🟠 **Закрыть старый репозиторий** `bez1655/HCG` — пока он публичный,
   утёкшие ключ Firebase и токен доступны всем.

3. 🟠 **Ротировать ключ Firebase** — он в 50 коммитах старого репозитория.
