# CYBER GAME — 3 независимые ветки проектов

Репозиторий разделён на 3 независимые Git-ветки:

1. **`hcg`** (папка `hcg/`) — Hapstore Cyber Game (Node.js сервер, Telegram-бот, Mini App, BUILD 2026-10-10.7).
2. **`acg`** (папка `acg/`) — Али-Баба (ALI2.0) (исходники с GitHub, инструкции синхронизации с HCG).
3. **`dcg`** (папка `dcg/`) — Duck’s Jackpot (маскот Джек Пот, стиль, мокапы, заглушки механики).
4. **`main`** — корневая ветка оркестратора Antigravity (`AGENTS.md`).

Каждая ветка подключена через `git worktree`, благодаря чему все 3 папки доступны одновременно в проекте.
