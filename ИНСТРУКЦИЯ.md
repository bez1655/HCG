# HCG — всё через сервер

Три задачи, каждая — одна команда **на сервере**. Компьютер нужен только чтобы
один раз загрузить архив.

```
deploy/1-СЕРВЕР.sh    развернуть игру
deploy/2-GITHUB.sh    отправить код в репозиторий
deploy/3-APK.sh       собрать приложение для Android
```

---

## ШАГ 0. Загрузить архив на сервер

**На вашем компьютере**, в PowerShell. Путь замените на свой:

```powershell
scp C:\Users\serge\Downloads\HCG-3v1.zip root@VM-744336:/root/
```

Введите пароль от сервера.

> Команда выполняется **на компьютере**, не в PuTTY. Если запустить её на
> сервере — будет ошибка.

**Дальше всё в PuTTY, на сервере.**

Распаковать:

```bash
cd /root
unzip -o HCG-3v1.zip
cd HCG-3in1
```

Проверить, что вы в нужном месте:

```bash
ls deploy/
```

Должны быть три файла: `1-СЕРВЕР.sh`, `2-GITHUB.sh`, `3-APK.sh`

---

## ЧАСТЬ 1. Развернуть игру

```bash
bash deploy/1-СЕРВЕР.sh
```

Занимает 5–10 минут. Скрипт сам:

- сохранит копию текущей версии и `.env` в `/root/`
- разложит файлы в `/var/www/hcg`
- пересоберёт образы начисто
- проверит, что внутри контейнеров действительно новый код
- напечатает команду отката, если что-то пойдёт не так

**Ваш `.env` не пострадает** — скрипт его бережёт и делает копию.

Затем два действия в Telegram:

1. Отправьте боту **новую** команду `/start`
   *(в старом сообщении кнопки не изменятся — они привязаны к нему)*
2. Проверьте `/pending`

## ЧАСТЬ 2. Отправить в GitHub

### 2.1 Создать репозиторий

В браузере: **https://github.com/new**

| Поле | Значение |
|---|---|
| Repository name | `HCG-Production` |
| Видимость | **Private** |
| Add a README file | ❌ не ставить |
| Add .gitignore | ❌ не ставить |
| Choose a license | ❌ не ставить |

> Три галочки не ставить — иначе GitHub создаст свои файлы и отправка упадёт
> с конфликтом.

Скопируйте адрес со страницы репозитория.

### 2.2 Создать токен доступа

GitHub не принимает пароль от аккаунта — нужен токен.

**https://github.com/settings/tokens?type=beta**

1. **Generate new token**
2. **Token name:** `HCG deploy`
3. **Expiration:** 90 days
4. **Repository access:** Only select repositories → `HCG-Production`
5. **Permissions** → Repository permissions → **Contents** → **Read and write**
6. **Generate token**
7. **Скопируйте сразу** — показывается один раз, начинается с `github_pat_`

### 2.3 Отправить

На сервере, в папке `/root/HCG-3in1`:

```bash
bash deploy/2-GITHUB.sh
```

Скрипт спросит адрес репозитория и запомнит его. При входе:
**логин** — ваш, **пароль** — токен из шага 2.2.

Чтобы не вводить руками, можно передать токен сразу:

```bash
GITHUB_TOKEN=github_pat_ваш_токен bash deploy/2-GITHUB.sh
```

Токен используется только в самой команде и **не сохраняется** в настройках git.

### 2.4 Включить защиту (один раз)

Репозиторий → **Settings** → **Code security**:

| Настройка | Значение |
|---|---|
| Secret scanning | **Enable** |
| Push protection | **Enable** |

**Push protection** не даст закоммитить секрет — этого не хватало в прошлый раз.

## ЧАСТЬ 3. Собрать приложение для Android

```bash
bash deploy/3-APK.sh
```

Скрипт сам поставит Java 17 и Android SDK — Android Studio не нужна. Адрес
игры возьмёт из настроек сервера и предложит подтвердить.

Первая сборка: **10–20 минут**, нужно около **4 ГБ** свободного места.

Готовый файл окажется здесь:

```
/var/www/hcg-apk/HCG-Admin.apk
```

### Как перенести на телефон

**Способ 1 — временная ссылка (проще всего).**

На сервере:

```bash
cd /var/www/hcg-apk
python3 -m http.server 8899
```

На телефоне открыть в браузере (IP сервера подставьте свой):

```
http://IP-СЕРВЕРА:8899/HCG-Admin.apk
```

После скачивания вернитесь в PuTTY и нажмите **Ctrl+C** — раздача остановится.

**Способ 2 — через компьютер.**

В PowerShell на компьютере:

```powershell
scp root@VM-744336:/var/www/hcg-apk/HCG-Admin.apk C:\Users\serge\Downloads\
```

Затем передайте файл на телефон любым способом.

**Способ 3 — постоянная ссылка через nginx.**

В конфиг вашего сайта добавьте:

```
location /app.apk { alias /var/www/hcg-apk/HCG-Admin.apk; }
```

Затем:

```bash
nginx -t && systemctl reload nginx
```

Приложение будет доступно по адресу `https://hcg.bez12.store/app.apk`

### Установка

1. Откройте файл на телефоне
2. Разрешите установку из неизвестного источника
3. Войдите: логин `admin` и пароль администратора

## Про приложение

Это **не отдельная игра**. Оно подключается к тому же серверу: ход из
приложения виден в Telegram и наоборот. Без интернета не работает.

Вход — по логину и паролю, Telegram не нужен. Версия для вас как
администратора.

---

## Порядок, если делаете всё сразу

1. **Часть 1** — сервер. Без обновлённого сервера приложение не сможет войти.
2. **Часть 3** — приложение.
3. **Часть 2** — репозиторий, когда удобно.

## Если что-то пошло не так

### Развёртывание

| Сообщение | Решение |
|---|---|
| `docker не установлен` | Проверьте, что вы на нужном сервере |
| `нет .env` | `cd /var/www/hcg && npm run setup-env -- --password 'пароль'` |
| `Telegram отверг токен (401)` | Токен отозван. Новый: @BotFather → /mybots → Bot Settings → API Token |
| `Telegram недоступен` | Нужен прокси: `TELEGRAM_PROXY=socks5://хост:порт` в `.env` |
| Кнопок в боте нет | Отправьте **новую** команду `/start` |

Откат — точный путь скрипт печатает в конце своей работы:

```bash
rm -rf /var/www/hcg
cp -r /root/hcg-backup-ГГГГММДД-ЧЧММСС /var/www/hcg
cd /var/www/hcg && docker compose up -d
```

### GitHub

| Сообщение | Решение |
|---|---|
| `Authentication failed` | Введён пароль вместо токена |
| `Updates were rejected` | Репозиторий создан с README — удалите и создайте пустой |
| `Permission denied` | У токена нет права **Contents: Read and write** |
| `в коммит попали файлы с секретами` | Скрипт защитил вас. Проверьте `.gitignore` |

### Сборка приложения

| Сообщение | Решение |
|---|---|
| `свободно ... МБ` | Освободите место, нужно ~4 ГБ: `df -h` |
| `не удалось установить Java 17` | Поставьте вручную: `apt install openjdk-17-jdk-headless` |
| Gradle падает | Повторите только сборку: `cd apk/android && ./gradlew assembleDebug --no-daemon` |
| Приложение не пускает | Сначала выполните часть 1 — нужен сервер от 30.07 или новее |

## Осталось сделать вручную

Скрипты этого не умеют:

1. 🔴 **Отозвать токен бота**, присланный в переписку. Он скомпрометирован.
   @BotFather → `/mybots` → Bot Settings → API Token
2. 🟠 **Закрыть старый репозиторий** `bez1655/HCG` — пока он публичный,
   утёкшие ключ Firebase и токен доступны всем.
3. 🟠 **Ротировать ключ Firebase** — он в 50 коммитах старого репозитория.
