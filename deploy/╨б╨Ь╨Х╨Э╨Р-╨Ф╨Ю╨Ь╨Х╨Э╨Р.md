# Смена домена HCG → hapstore.cyber-game.online

Старый адрес `hcg.bez12.store` в коде заменён. На сервере нужно то же самое в **живом** `.env` и в прокси.

## DNS

A-запись (или CNAME) **`hapstore.cyber-game.online`** → IP VPS.

## На VPS (после DNS)

```bash
cd /var/www/hcg
grep WEB_APP_URL .env
# должно стать:
# WEB_APP_URL=https://hapstore.cyber-game.online
```

Если ещё старое:

```bash
sed -i 's#https://hcg.bez12.store#https://hapstore.cyber-game.online#g' /var/www/hcg/.env
```

Caddy / панель: сайт на **hapstore.cyber-game.online**, прокси на контейнер как раньше (часто `127.0.0.1:3001`). TLS выпустится сам, когда DNS уже смотрит сюда.

Пересоздать бота и приложение, чтобы подхватили URL кнопки «ИГРАТЬ»:

```bash
cd /var/www/hcg
docker compose up -d --force-recreate
```

## Telegram

В @BotFather → бот → Bot Settings → Domain / Mini App URL:  
`https://hapstore.cyber-game.online`

## APK

Старое приложение ходит на старый домен. Нужна **новая сборка** с  
`VITE_API_BASE_URL=https://hapstore.cyber-game.online`.

Mini App в боте после смены `.env` и BotFather — без APK.
