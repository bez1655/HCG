# HCG — выжимка для переноса в новый чат

## Цель
Telegram Mini App «Hapstore Cyber Game» — игра-ходилка (65 клеток) для магазина
цифровых товаров. Бот **@hcg1_bot**, домен **hapstore.cyber-game.online**.

## Правила работы
- Общение по-русски; технические комментарии в коде — по-английски.
- Пользователь **не программист**: пошаговые инструкции с точными путями
  (Windows PowerShell vs PuTTY на сервере).
- **Проверять эмпирически**, не чтением кода. Каждое исправление — **возвратом
  поломки**: вернул баг → тест упал → восстановил → прошёл.
- Честно называть свои регрессии (их было 8, все исправлены).
- Инфографику делать **кодом (PIL)**, не нейросетью — коверкает кириллицу.
  Фон можно генератором, текст поверх кодом.

## Инфраструктура
- Сервер `root@VM-480084`, проект `/var/www/hcg`, контейнеры `hcg_app`,
  `hcg_bot`, `hcg_proxy`. Реверс-прокси — **Caddy** (не nginx!).
- Том данных называется **`hcg_hapstore-data`** (Compose добавляет префикс проекта).
- Рабочая копия `/home/user/HCG`, ветка `security-hardening`.
- **Между сессиями пропадают** `node_modules` (корень и `bot/`), слетают флаги
  исполняемости, чистится `/tmp`. Лечение: `mkdir -p /tmp/npm-global/lib
  /tmp/npm-global/bin`, `npm ci` в корне и в `bot/`, `npm run fix-perms`.
- `npm run test:e2e` пересобирает `dist`, прямой `npx vitest --config
  vitest.e2e.config.ts` — **нет**.
- Коммиты: `git -c user.name="HCG" -c user.email="hcg@local"`.

## Сделано в этой сессии
1. **Скрипты переезда на новый сервер**: `deploy/СНЯТЬ-СО-СТАРОГО.sh`,
   `deploy/ПОСТАВИТЬ-НА-НОВЫЙ.sh`, `deploy/БЕЗ-ПРОКСИ.sh`. Учитывают Caddy
   (сертификаты в `/var/lib/caddy/.local/share/caddy`, не в `/etc/letsencrypt`)
   и автоопределение имени тома.
2. **Кнопка «СПРАВКА»** в главном меню — экран `HelpScreen.tsx` с разбором всех
   бонусных/штрафных клеток. Данные из `cells.json` (не дублируются). Крупный
   шрифт 15–20px, тёмные подложки `rgba(0,0,0,0.62)`, фон `public/help-bg.jpg`.
3. **Результат каждого хода** — модуль `src/game/turnOutcome.ts`, компонент
   `TurnOutcomeCard.tsx`, событие `turn:outcome` в персональную комнату
   `player:<id>`. Дубль в бота. Работает и на обычных клетках («Приза нет»).

Метрики: **440 unit + 176 e2e = 616 тестов**, все зелёные. Сборка **2026-08-16.1**.
Коммиты: `17564de` (том), `dfdbdc9` (справка + результат хода).

## Решения
- Новый сервер: **4 ядра / 4 ГБ, Голландия** (вместо 2/2 в России). Замеры:
  игра не упирается в процессор (11 000 ходов/с на ядро). В Голландии Telegram
  доступен напрямую → после переезда запустить `БЕЗ-ПРОКСИ.sh` и выключить
  `hcg_proxy`.
- Архивы паковать Python-ом с флагом UTF-8 (`zi.flag_bits |= 0x800`), иначе
  русские имена бьются на Windows.
